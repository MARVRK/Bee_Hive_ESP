# BOM — Bee Hive V2

## Основные модули
- 1× ESP32-WROOM-32D
- 1× A7670E-FASE (4G LTE + GPS)
- 1× HW-465A BMS (1S2P, 5V/3A)
- 1× HX711 (АЦП для тензодатчиков)
- 4× тензодатчики 50 кг (тест) / 20 кг (финал)
- 1× SHT30 (температура + влажность)
- 1× OLED 0.96" или 1.3" I²C (SSD1306 / SH1106)
- 1× DS3231 RTC модуль с батарейкой CR2032
- 2× 18650 аккумулятор

## Хранение
- 1× MicroSD модуль (SPI)
- 1× MicroSD карта 8 ГБ+

## Пассивные компоненты
- 1× конденсатор 470 мкФ электролитический (на VBAT A7670E, критично!)
- 2× резистор 100 кОм (делитель напряжения батареи, IO34)
- 2× резистор 4.7 кОм (pull-up I²C: SDA IO21, SCL IO22)

## Интерфейс
- 2–3× кнопка тактовая
- кабели сигнальные (для SHT30 и OLED — до 1 м)

## Прочее
- корпус с кабельными выводами
- 1× внешняя антенна GSM (опционально)
